Privacy Policy

Last updated: 21 October 2026

1. What ShortsStudio is

ShortsStudio is a private tool run by the owner of the YouTube channel Teto's Terrific Recipes on their own computer. It is used only by that person to upload and schedule videos on their own YouTube channel. It is not a public service and it has no other users.

2. Which Google data is accessed

After the channel owner signs in with Google and grants access, ShortsStudio uses the YouTube Data API to:

  • read the basic details of the owner's own channel (channel name and ID) to make sure videos go to the right channel;
  • upload videos made by the owner, with title, description and tags written by the owner's tool;
  • set or remove the scheduled publication time of those videos and read their processing and privacy status.

ShortsStudio does not read comments, subscribers, messages, analytics of other people, or any data of other users.

3. How data is stored

  • All data stays on the owner's own computer. There is no ShortsStudio server and no cloud database.
  • The Google access tokens are stored encrypted with the Windows Data Protection API for the owner's Windows account and are never written to logs or shared.
  • A local record of uploads (video ID, title, schedule, status) is kept so the same video is never uploaded twice.

4. Sharing

No data received from Google APIs is sold, shared with third parties or used for advertising. It is used only for the purposes listed above. ShortsStudio's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. YouTube API Services

ShortsStudio uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and Google's Privacy Policy applies to data processed by Google.

6. Revoking access and deleting data

Access can be revoked at any time in the Google account settings at myaccount.google.com/permissions. ShortsStudio's own "disconnect" function also revokes the access and deletes the stored tokens. The local upload record can be deleted by the owner at any time.
